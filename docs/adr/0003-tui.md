# ADR 0003 — TUI i stället för web-GUI (skiss)

- **Status:** Skiss/riktning — 2026-09-04
- **Beslut:** Bygg en **terminal-UI (TUI)** som primärt gränssnitt i stället för
  web-konsolen. Ramverk: **bash + whiptail** (newt). Web-GUI:t (api/web) fryses
  som referens; TUI:n blir standardgränssnittet.
- **Ersätter riktningen i:** web-onboarding-omskrivningen (pausad i BACKLOG).

## Varför whiptail
- **Noll extra install** — finns på i princip varje Debian/PVE-host (`/usr/bin/whiptail`, paket `whiptail`). Passar etoset "self-contained, för folk utan PBS-maskin".
- **Matchar bash-CLI:t** — TUI:n är bara ännu en frontend; den *shell:ar ut* till samma `lxc-offsite`-kommandon (lås/preflight/audit återanvänds gratis), och läser data via `lxc-offsite --json`.
- **SSH-vänligt** — körs där man ändå administrerar hosten. `dialog`/`fzf` saknas på hosten → undviks.
- Alternativ om app-känsla önskas senare: Python **Textual** (rikare live-dashboard, men kräver pip/venv). Noteras, ej valt.

## Prioritet (användarens fokus)
1. **Enkel restic-setup** (repo/sftp/lösen/init) — högst
2. **Exportera DR-nyckel** (framtida återställning)
3. **Backup — alla eller enskild gäst**
4. **Restore**
5. Metrics & övrigt — med, men lägre fokus

## Skärmkarta
```
Huvudmeny
├─ 1. Setup / onboarding (restic)      ← wizard: motor→läge→sftp→lösen→init
├─ 2. Säkerhetskopiera                 → [Alla skyddade] / [Välj gäst…]
├─ 3. Återställ                        → gäst → snapshot → nytt vmid → storage → kör
├─ 4. Exportera DR-nyckel              → varning → repo-URL + lösen (textbox/fil)
├─ 5. Status & metrics                 → senaste körning, offsite-storlek, snaps, verify
├─ 6. Underhåll                        → prune (dry→skarp) / verify / test-restore
└─ 0. Avsluta
```

## Arkitektur
- `lib/tui.sh`, ny dispatcher-subkommando **`lxc-offsite tui`**.
- TUI:n **anropar CLI:t** (`"$LXCO_BIN" --json <cmd>` för data, `"$LXCO_BIN" <cmd>`
  för åtgärder) → ingen dubblerad affärslogik, samma envelope som web-UI:t använde.
- Ingen egen state; config skrivs till `/etc/lxc-offsite/config` (secrets till
  `RESTIC_PASSWORD_FILE` 0600 + pekare i Vaultwarden).
- `lxc-offsite tui --selftest` — icke-interaktiv wiring-koll (ingen TTY krävs).

## Status
Skelett byggt (huvudmeny + setup-wizard + backup/restore/export/status/underhåll
wire:ade mot CLI:t). Kräver TTY för att köras interaktivt. Kvar: fintrimma
formulär, felhantering, metrics-panelen, och koppla setup-skrivningen mot skarp
config först efter användarens klartecken.
